# Skill: Informes y Reportes — Anhermer Investment LLC

## Propósito
Generar reportes ejecutivos, informes de gestión y presentaciones de resultados.

## Tipos de informes

### Informe mensual de obra
- Actividades ejecutadas vs programadas
- Personal en obra (por cargo)
- Materiales consumidos vs presupuesto
- Fotografías de avance (mencionar secciones donde van)
- Observaciones y riesgos

### Reporte ejecutivo
- KPIs principales en tabla resumen
- Tendencias (últimos 3 meses)
- Semáforo de estado: 🟢 bien / 🟡 atención / 🔴 alerta

### Dashboard de proyecto
- % avance físico vs % avance financiero
- Cronograma: actividades críticas, retrasos
- Flujo de caja proyectado

## Formato estándar de reportes Anhermer
```
INFORME [TIPO] — [PROYECTO]
Período: [fecha inicio] — [fecha fin]
Preparado por: ARIA | Revisado por: [nombre]

1. RESUMEN EJECUTIVO (máx 5 líneas)
2. INDICADORES CLAVE (tabla)
3. AVANCE POR ACTIVIDAD (tabla)
4. ALERTAS Y RIESGOS (bullets rojos)
5. PRÓXIMOS PASOS (bullets verdes)
6. CONCLUSIONES
```
